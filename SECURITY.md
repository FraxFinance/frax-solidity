# Security Policy

## Reporting a Vulnerability

Please do not open a public GitHub issue with vulnerability details.

Frax Finance's public bug bounty documentation asks researchers to submit
smart-contract vulnerability disclosures privately. Prepare a private GitHub gist
with the proof of concept, write-up, and any relevant code, then share the
private gist link with the Frax team through an official Frax communication
channel such as Twitter/X, Telegram, Discord, or Signal.

- Bug bounty documentation: https://docs.frax.finance/smart-contracts/bug-bounty
- Fraxtal security documentation: https://docs.frax.com/protocol/security/bugbounty

The public bug bounty covers smart-contract code that manages Frax Protocol
value and/or user deposited value. Front-end bugs, visual bugs, and server-side
code for web applications interacting with the protocol are outside the stated
scope of the smart-contract bounty.

If you are unsure whether a finding is in scope, still avoid public disclosure
of technical details until a verified Frax maintainer confirms the appropriate
private disclosure path.
